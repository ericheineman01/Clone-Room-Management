CLONE TIMELINE — iPhone Home Screen app

WHAT IT DOES
- Shows the weekday and calendar date for each configured number of days ago.
- Starts with 2, 7, 12 and 14 days, each with an editable task name.
- Add, edit, and remove intervals.
- Saves your list on the device and works offline after first load/cache.

INSTALL
This is a small Progressive Web App (PWA). iOS requires it to be served from an HTTPS website
(or localhost) to install it as a Home Screen web app. The ZIP contains the complete site.

Simple hosting option:
1. Create a free GitHub repository and upload the five files in this folder to its root.
2. In the repository, open Settings -> Pages.
3. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
4. Wait for GitHub Pages to publish the HTTPS address.
5. On your iPhone, open that address in Safari.
6. Tap Share -> Add to Home Screen -> Add.

You can also host these files on any HTTPS static web host. Keep all files together.
Your task names and intervals are stored locally in Safari on that iPhone. They are not synced
between devices. If you clear Safari website data, the saved list may be erased.
